# SpecForge Bootstrap — Batty Joe

This repository is a SpecForge-managed project.

## Bootstrap

A fresh human or AI session MUST:

1. Read `specforge.yaml`.
2. Read the manifest-declared authoritative Batty Joe product specification.
3. Read the manifest-declared SpecForge Core canonical data model.
4. Load the applicable rules and workflows.
5. Inspect open changes and recent forensic history.
6. Preserve Repository Completeness and Forensic Traceability.
7. Treat the Batty Joe specification as Product Intent.
8. Do not invent material gameplay or product behaviour.
9. In Controlled mode, do not implement a material proposal until the exact proposal revision has been explicitly approved.

## Current adoption state

Batty Joe existed before SpecForge adoption. Existing source files and `batty-joe-dev-spec-v1.5.0.yaml` are an imported baseline, not evidence that the earlier development history was SpecForge-governed.

Pre-adoption history MUST NOT be fabricated. Where historical provenance is unavailable, record that limitation explicitly.
