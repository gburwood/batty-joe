# Source of Truth Rules

1. Incoming requests are evidence of requested work, not automatically approved intent.
2. The approved authoritative specification defines intended product behaviour.
3. Implementation must not silently redefine product intent.
4. A discrepancy between specification and implementation must be investigated.
5. Material behavioural changes follow the configured approval policy.
6. In Controlled mode, approval is required before a materially changed proposal becomes authoritative.
